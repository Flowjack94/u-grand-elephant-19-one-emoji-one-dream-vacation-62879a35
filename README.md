## Entry

A single emoji, nothing else — the dream vacation in one character:

🌌 — the aurora borealis. Standing under the northern lights in Iceland or Norway is the bucket-list trip that makes a stranger want to book the flight.

## How it works

`main.py` writes exactly that one emoji (U+1F30C) to `/output/entry.txt` — no extra text, no trailing newline.

```sh
python3 main.py
cat /output/entry.txt
```
